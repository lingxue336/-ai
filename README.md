# 一小步：初中数学拍题与精准补弱短片

项目目录：`E:\自动识别视频ai`。后端使用 Java 21 / Spring Boot，照片识别和视频转字幕默认全部在本机运行。

## 打开使用

双击本目录的 **启动系统.cmd**，然后打开 <http://localhost:8086/>。

8080 端口属于电脑上的另一个项目，本项目不占用它。启动器不会停止其他项目。

已安装的本地组件：Ollama + `qwen3-vl:4b`（约 3.3 GB）、Whisper.cpp + small 中文语音模型（约 488 MB）、FFmpeg、yt-dlp。程序位于 `tools`，模型位于 `models`。初次加载识图模型可能较慢。下载完成后，识题、语音转写、剪辑不依赖云端模型；从 B 站导入视频仍需联网。

## 学生怎么用

1. 上传或粘贴一道初中数学题的照片，尽量包含自己的解题步骤。照片会原位替换上传框；可更换、旋转和还原。点击“裁剪题目”打开大图，拖动八个边角或选框内部，点击“应用裁剪”确认，取消不会改动照片。
2. 选择年级，可补充“我卡在哪一步”。点击识别，核对抄录的题干与作答依据。
3. 确认具体卡点。没有作答时，系统只能提出候选步骤，不能凭题目断言学生不会什么。
4. 系统从已经剪好的短片中，结合题目、作答和片段内容进行筛选，只播放独立短片。
5. 看完反馈“这一步懂了”或“看完还卡着”，在学习记录中回看。

本地没有覆盖当前具体卡点的合适短片时，点击 **“联网查找并剪成短片”**。可修改知识点关键词，也可展开后粘贴具体 B 站视频链接。系统依次搜索、获取视频、在本机转字幕、结合画面定位讲解、生成独立 MP4，再复核匹配；全程显示阶段进度。

每次最多尝试 3 条候选视频，单条最长 20 分钟、下载上限 512 MB。只把搜索关键词发送到 B 站，不发送题目照片；模型分析默认在本机完成。遇到登录、验证码、网络限制或没有适配区间时明确提示，可换关键词或指定链接，不推整节课兜底。

**联网自动生成的短片标注“AI 内容核对，未经老师人工审核”**，不会伪称老师审核。老师手动发布仍须预览确认。AI 判断可能有误，请核对片段实际讲解；首次生成可能需要数分钟，之后可复用已保存短片。

## 老师怎么准备视频

1. 在“老师工作台”粘贴 B 站标准视频链接，选择年级后导入。支持 `?p=2` 等分 P 链接；不支持短链、付费/登录绕过。也可上传本地教学视频。
2. 优先导入已有字幕；没有字幕时点击“本地语音转字幕”，或上传 SRT / VTT / B 站 JSON 字幕。上传的视频会检查格式，必要时转成浏览器可播的 H.264/AAC MP4。
3. 点击“AI 生成打点建议”，或手动选择起止位置。系统同时参考带时间戳字幕和真实视频抽帧；长视频分批处理，时间由真实字幕编号映射，不能由模型凭空猜测。
4. 每段选择一个具体知识卡点，填写“这段解决哪一步不会”，逐段预览并调整起止位置，勾选审核。
5. 点击“剪成独立视频并发布”。系统实际重新编码生成 MP4，验证时长后才加入学生推荐库。每段限制 5 秒至 6 分钟。

自动字幕可能把数学符号、数字和同音词识别错；AI 的打点和标签也可能有误。**建议不等于已发布，必须预览核对。** 所有片段保留原视频链接、作者、原始起止时间。只导入有权用于相应用途的教学资料；对外部署或分发前另行确认版权许可。

## 已有可体验的真实示例

- `使用示例/判别式错题.jpg` 是程序生成的测试题，不是真实学生隐私照片。
- 题目是 `x² − 2x + 3 = 0`，解答正确算出 `Δ = −8`，但错误写成有两个不相等实数根。
- 本地模型已能定位“根据判别式正负判断实数根情况”，不把已经正确的计算列为错误。
- 资料库已导入 [乐乐课堂的根的判别式教学视频](https://www.bilibili.com/video/BV18x411x79x/)，原长约 196 秒。
- 已实际剪出第 **53.5–73.8 秒**的示例，独立 MP4 实测 **20.323 秒**，解释 Δ＜0 无实数根及判别式含义。示例做过字幕/画面和播放的技术核对，正式教学仍建议老师复核。

目前是小规模可运行版本：知识卡点词表覆盖多个初中数学主题，支持本地匹配及联网补齐，**不是覆盖初中全部知识点的视频库，也没有做大规模识别准确率评测**。不能承诺任意照片都准确、每个卡点都能在网上找到适配短片，或所有 B 站链接都可获取。

## 数据、隐私与备份

联网处理已用配方法符号错题实际验证：从约18分钟的B站讲解中生成约3分18秒的独立短片，包含对应例题、符号解释和结论。系统会对选中区间的字幕和画面再作一次独立核对；未经边界核对的早期自动测试片保留文件，但不再推荐。自动审核仍可能出错，页面明确标注尚未经过老师人工审核。

- 新版数据在 `data/precision/library.json`，照片在 `photos`，原片在 `sources`，独立短片在 `clips`，处理日志在 `logs`（均位于 `data/precision` 下）。
- 默认模型地址为 `127.0.0.1:11434`，照片不发送给云模型。老师若改成远程模型地址，照片和字幕会发送到所选服务。
- 旧版源码和旧数据已备份到 `backup/before-photo-redesign-20260920-151726`，旧数据未删除。旧演示检索数据与新版学生推荐库隔离。
- 这是单机版本，默认只监听本机地址；没有多用户登录、角色权限或班级隔离。**请勿直接暴露到公网供儿童使用。** 测试照片和历史保留在本机，可按实际学校隐私要求另行制定保留/删除机制。
- 正在进行的后台任务不跨重启恢复；已完成的视频、短片、识题记录会保存。电脑关闭后需重新启动服务。

## 开发和验证

在本项目目录运行 `mvn test`，或 `mvn package` 构建，再通过启动器运行。需要 Java 21、Maven；本机工具位于 `tools`。

核心实现：

- `PrecisionService`：照片证据诊断、卡点确认、同技能候选的内容匹配、字幕与画面联合打点建议。`LearningScope` 对判别式正负不同的已知条件作额外拦截，不把 Δ＜0 的专讲推给 Δ＝0 的卡点。
- `PrecisionMedia`：B 站来源导入、视频规范化、本地语音转写、真实 FFmpeg 剪辑和时长校验。
- `PrecisionStore`：新数据独立持久化；`ModelGateway`：本机视觉/文本模型调用。
- `WorkJobs`：后台媒体与学生识图分开处理，避免下载视频占满识图队列。
- `static/index.html / app.js / app.css`：学生拍题、学习记录与老师工作台。

验证记录见 `验证说明.md`。开发资料：[Ollama API](https://docs.ollama.com/api/chat)、[Qwen3-VL 本地模型](https://ollama.com/library/qwen3-vl:4b)、[Whisper.cpp](https://github.com/ggml-org/whisper.cpp)、[FFmpeg](https://ffmpeg.org/)、[yt-dlp](https://github.com/yt-dlp/yt-dlp)。
